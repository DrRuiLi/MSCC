# Demo chemical formulas

Character vector of example chemical formulas for demos, examples, and
benchmarking of chemform helpers.

## Usage

``` r
demo_chemform
```

## Format

A character vector of length 107.

## Examples

``` r
head(demo_chemform)
#> [1] "C4H4Cl1N3O1" "C7H13N5O1"   "C7H12Cl1N5"  "C9H17N5O1"   "C5H6Cl1N3O1"
#> [6] "C6H11N5O1"  
```
