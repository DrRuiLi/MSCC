# chemform_isotopes_pattern_enviPat

update of enviPat::isopattern, which do not output the formula of
isotopologues this function return isotopologues with abundance more
than 0.01%

## Usage

``` r
chemform_isotopes_pattern_enviPat(chemform, thresh = 0.1)
```

## Arguments

- chemform:

  chemical formula

## Value

isotopes pattern
