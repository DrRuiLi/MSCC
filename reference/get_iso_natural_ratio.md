# Build isotopologue natural ratio baseline

Build isotopologue natural ratio baseline

## Usage

``` r
get_iso_natural_ratio(formula, iso_ele, ratio_matrix)
```

## Arguments

- formula:

  Chemical formula.

- iso_ele:

  Isotope notation.

- ratio_matrix:

  Numeric matrix with isotopologues as rows.

## Value

Matrix with natural baseline ratios aligned to `ratio_matrix`.
