# One maximum common substructure, in canonical atom ids.

One maximum common substructure, in canonical atom ids.

## Usage

``` r
rdkit_mcs_pairs(from_smiles, to_smiles)
```

## Arguments

- from_smiles:

  Substrate SMILES.

- to_smiles:

  Product SMILES.

## Value

A list with canonical smiles and atom-id pairs.
